# GPO でのスケジュールタスク配布手順

> 方式B（GPO）の手順です。GPO を追加しない場合は [Deploy-Startup.md](Deploy-Startup.md)（方式A）を使ってください。

全端末で **毎日 1 回 ＋ 起動 5 分後** に `Get-DeviceInventory.ps1` を SYSTEM 権限で実行し、
共有フォルダに `<端末名>.csv` を書き出させる設定です。
病棟などで再起動せずに動き続ける端末も、毎日実行するので収集できます。

## 1. 共有フォルダを作る

ファイルサーバー（例: `fs01`）に `D:\inventory` を作り、`inventory$` という名前で共有します（末尾の `$` で一覧に表示されなくなります）。

```
D:\inventory\
  Get-DeviceInventory.ps1     … 端末で実行するスクリプト（リポジトリの terminal\ にあるもの）
  raw\                        … 各端末の CSV が入る
  台帳.csv                    … Merge-Inventory.ps1 が作成・更新
```

### アクセス権

| 対象 | 共有のアクセス許可 | NTFS のアクセス許可 |
|---|---|---|
| `D:\inventory` | Domain Computers: 変更 / 情報システム担当: フルコントロール | Domain Computers: 読み取りと実行 / 情報システム担当: フルコントロール |
| `D:\inventory\raw` | （上と同じ） | Domain Computers:「ファイルの作成/データの書き込み」「属性の書き込み」（**このフォルダーのみ**）<br>CREATOR OWNER: 変更（**ファイルのみ**） |

- 各端末は自分が作った CSV だけを上書きでき、他の端末の CSV は読めません。
- Office ライセンス情報が入るため、`raw` と `台帳.csv` は情報システム担当だけが読めるようにしてください。

## 2. GPO にスケジュールタスクを登録する

1. 「グループ ポリシーの管理」で、電子カルテ端末が入っている OU に新しい GPO（例: `端末台帳収集`）を作ってリンクする
2. GPO を編集し、
   **コンピューターの構成 → 基本設定 → コントロール パネルの設定 → スケジュールされたタスク**
   を右クリック →「新規作成」→「**スケジュールされたタスク (Windows 7 以降)**」
3. 以下のように設定する

| タブ | 項目 | 値 |
|---|---|---|
| 全般 | 操作 | 置換 |
| 全般 | 名前 | `端末台帳収集` |
| 全般 | 実行するユーザー アカウント | `NT AUTHORITY\System` |
| 全般 | | 「ユーザーがログオンしているかどうかにかかわらず実行する」「最上位の特権で実行する」 |
| 全般 | 構成 | Windows 7, Windows Server 2008 R2 |
| トリガー ① | 毎日 | 10:00（全端末が同じ時刻に集中しないよう「遅延時間を指定する（ランダムに遅延）: 30 分」） |
| トリガー ② | スタートアップ時 | 「遅延時間を指定する: 5 分」 |
| 操作 | プログラムの開始 | プログラム: `powershell.exe` |
| | 引数の追加 | `-NoProfile -ExecutionPolicy Bypass -File "\\fs01\inventory$\Get-DeviceInventory.ps1" -OutputDir "\\fs01\inventory$\raw"` |
| 設定 | | 「スケジュールされた時刻にタスクを開始できなかった場合、すぐにタスクを実行する」<br>「タスクを停止するまでの時間: 30 分」 |
| 条件 | | 「コンピューターを AC 電源で使用している場合のみタスクを開始する」の**チェックを外す**（ノート PC 対策） |
| 共通 | | 「適用されなくなったときにこの項目を削除する」にチェック（GPO を外せばタスクも消える） |

4. 端末側は次回の GPO 更新（再起動、または最大 90 分後）でタスクが作られます。
   試験端末では `gpupdate /force` を実行すれば、すぐに反映されます。

> `run-inventory.bat`（`Get-DeviceInventory.ps1` を同じフォルダに置く）を GPO のスタートアップスクリプトに登録する方法もありますが、
> 再起動しない端末は収集できないため、上のスケジュールタスク方式を推奨します。

## 3. 試験運用（全台展開の前に必ず）

Windows 7 の端末と Windows 10/11 の端末を 1 台ずつ選び、管理者権限の PowerShell で手動実行して結果を確認してください。

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File "\\fs01\inventory$\Get-DeviceInventory.ps1"
```

`-OutputDir` を付けなければ、結果は画面に表示されるだけです。次の点を確認します。

- `IPAddress` / `MACAddress` に電子カルテ網の NIC が入っているか
- `OfficeProduct` / `OfficeLicenseKey` が入っているか（Office が無い端末は空欄）
- `EstimatedStartDate`（推定導入日）が妥当な日付か
- 実行時間（通常 10〜30 秒。Windows 7 ではライセンス照会に 1 分ほどかかることがあります）

確認できたら GPO を試験用の OU にだけリンクし、`raw` に CSV ができることを確かめてから、全体の OU に広げてください。

## 4. 停止・撤去

「共通」タブで「適用されなくなったときにこの項目を削除する」にチェックしてあれば、GPO のリンクを外すだけで次回の GPO 更新時に端末からタスクが消えます。
